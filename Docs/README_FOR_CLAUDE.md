# BTGE — Start Here

For a new AI assistant or engineer picking up the Balanced Team Generation
Engine.

This file is a signpost. It contains no business rules, no design decisions, and
no summary of the specification — by design. Read the authoritative documents
themselves.

## Reading order

Read these in order, in full, before writing any code.

1. **`Docs/README.md`** — the documentation map for the project.
2. **`Docs/engineering/BTGE_Design_Knowledge_Base.md`** — the **Design
   Authority**.
3. **`Docs/engineering/BTGE_Engineering_Specification.md`** — the
   **Implementation Authority**.

## Authority

- The **Knowledge Base** is the **Design Authority**.
- The **Engineering Specification** is the **Implementation Authority**.
- **If a conflict exists, the Knowledge Base governs product intent and the
  Engineering Specification must be updated accordingly.**

## Working rules

- **Implement only from the approved documents.**
- **Do not redesign BTGE.**
- **Do not reopen approved product decisions.**
