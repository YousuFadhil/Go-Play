# Software Requirements Specification (SRS)

## Functional Requirements

-   User Registration
-   User Login
-   Group Management
-   Match Management
-   Match Registration
-   Reserve Auto Promotion

## Business Rules

-   No overlapping match registrations.
-   First registered players are confirmed.
-   Remaining players join reserve list.
-   First reserve is promoted automatically after cancellation.

## Non-Functional Requirements

-   Mobile-first.
-   Secure authentication.
-   PostgreSQL + Supabase.
