# Product Requirements Document (PRD)

> This document is the official product reference for the MVP.

## Goal

Build an MVP for managing amateur football groups and matches.

## Target Users

-   Players
-   Group Owners

## MVP Scope

-   Register / Login
-   Create & Join Groups
-   Create Matches
-   Match Registration
-   Reserve List with Auto Promotion

## Out of Scope

-   Team Generator
-   Rating Engine
-   Statistics
-   Leaderboards
-   Notifications

## Success Criteria

-   10 real users
-   3 active groups
-   10 real matches
-   Users continue using the app for at least two weeks.
