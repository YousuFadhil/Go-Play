# Task Request

## Objective

Implement only the requested task.

---

## Before Starting

1. Read the project documentation.
2. Understand the existing implementation.
3. Identify dependencies.
4. Verify that the task belongs to the current MVP.

---

## During Implementation

- Follow the approved documentation.
- Keep the implementation simple.
- Reuse existing code whenever possible.
- Do not introduce unnecessary complexity.
- Do not change architecture without approval.
- Do not add features outside the requested scope.

---

## If You Discover a Better Solution

Do not implement it immediately.

Instead:

- Explain the current solution.
- Explain the proposed solution.
- Explain the advantages.
- Wait for approval.

---

## Deliverables

When the task is complete, provide:

### Summary

Brief description of what was implemented.

### Files Changed

List of modified files.

### Commands

Any commands required to run the project.

### Testing

Explain how to verify the implementation.

### Issues

Mention any remaining limitations or known issues.

### Next Task

Recommend one logical next task only.
